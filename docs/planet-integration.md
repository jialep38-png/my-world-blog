# 小星球融入霁风的小圈

目标仓库是 `jialep38-png/my-world-blog`。小星球来源是用户已有的 My Little Orbit 作品项目；没有改动来源项目和它的发布站点。

## 展示设计

- 首页保留原花田插画、个人介绍、文章与项目列表。小星球仅作为一排小幅陈列，不成为首页主视觉。
- 新增 `/planets/` 展廊和五个 `/planets/<作品 id>/` 页面，使用博客既有的宋体、楷体、纸色、细分隔线和夜间模式。
- 顺序为昨天，今天、删了一百遍、思念若是一首诗、雨终曲、芥兰。
- 图版默认可读，访客点击「转一转」才创建同源三维 iframe。点击「图版」会卸载 iframe；父页面控制离屏暂停和主题同步。
- 图片放大复用博客原有 Lightbox，支持键盘、触摸缩放和图版切换。原文章、日期与个人信息没有重写。

## 素材与更新

`src/data/planets.ts` 保存作品说明、顺序和图版关系。25 幅图片来自同一作品的既有三维导出；导入时用原 `build.json` 校验，原始图像清单保存在 `planet-photographs.json`。Astro 在构建时生成适合首页、展廊、详情和灯箱的响应式 WebP。

```sh
node scripts/import-planet-images.mjs /path/to/my-little-orbit/web
```

只复制公开图版，不复制参考图、GLB、原项目文章或私有文件。三维素材和依赖通过另一份导入器维护，见 `orbit-runtime.md`。图版对应场景版本不因本轮博客排版变更而重标记。

## 检查

```sh
SITE_URL=https://jialep38-png.github.io SITE_BASE=my-world-blog npm run ci
```

使用正式 Pages 的子路径构建；检查首页、六个星球页面、图片加载、夜间模式、手机布局、灯箱开关及键盘焦点、三维按需打开/回退、相邻作品链接。真实设备与长期 GPU 性能不在本轮验证范围。
