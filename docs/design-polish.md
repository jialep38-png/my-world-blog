# 小圈界面与阅读体验优化

日期：2026-09-27。基于小星球整合后的博客主分支，保留原有花田主图、内容与五件作品。

## 参考与取舍

| 参考 | 应用于小圈的设计 |
| --- | --- |
| [Beautiful UI](https://www.beautifului.dev/) | 侧栏层级、清晰的搜索入口、加载与空结果反馈 |
| [beUI Tabs](https://beui.dev/components/motion/tabs) | 最近更新的滑动选择指示、主题切换的轻量过渡 |
| [Rare UI Folder](https://www.rareui.com/components/foldercomponent) | 分类入口的纸张与文件夹轮廓、克制的悬停反馈 |
| [Transitions](https://transitions.dev/) | 统一缓动、短暂淡入、弹层过渡、减少动态效果适配 |
| [shadcn/ui Command](https://ui.shadcn.com/docs/components/base/command) | 分组搜索、键盘导航、明确的焦点与状态 |

参考用于交互原则和视觉层级。组件使用 Astro、原生 HTML/CSS/TypeScript 实现，没有复制第三方源码，也没有引入 React、Tailwind 或动画依赖。Rare UI 组件页的浏览器演示遇到站点验证，参考范围限于可读取的页面内容。

## 改动

- 为纸色、暖灰、低饱和玫瑰色建立公共表面、阴影、圆角、动效和控件字体变量；深浅主题保持一致。
- 首页保留花田主图，小星球以五枚小图展示；增加标题层级、最近内容筛选、文章卡片和分类入口。
- 整理桌面侧栏与手机导航，搜索、当前栏目、主题和阅读按钮使用一致的控件语言。
- 原生全站搜索只在打开时载入索引，支持中文、标题、标签和简短摘要检索，提供快捷入口、空状态、失败重试、方向键、Enter 和 Esc。索引包含 44 项并排除草稿；小记提供栏目入口。
- 文章增加估算阅读时长、复制链接反馈、细线阅读进度、当前小节目录和手机折叠目录。
- 项目卡片统一间距与表面样式，外部链接提供可访问名称和更大的触控区域。
- 关于页补充小星球入口，并修复原有栏目链接在 GitHub Pages 子路径下的跳转。
- 搜索弹层加入背景滚动锁定；小星球在任何 dialog 打开时发送暂停消息。回到图版会移除三维 iframe。
- 保留正常文档导航，以 View Transitions 渐进增强过渡；减少动态效果设置下禁用装饰动画。

- 正式子路径 `SITE_BASE=my-world-blog` 的 `npm run ci` 通过：0 errors、0 warnings、38 条既有 hints；66 个 Astro 页面完成构建，callout、code block、gallery 检查通过。
- 构建产物的 66 个非测试 HTML（含独立三维 viewer）、120 个站内目标检查通过。已有 `/ci/markdown-fixtures/` 测试夹具的两张根路径 favicon 不纳入访客页面链接结论。
- 搜索工作模块完成根路径和子路径两种构建；44 项索引链接、重复 ID、草稿排除以及中文排序/多关键词匹配通过检查。
- 浏览器检查覆盖 320、390、768、1280 像素，深浅主题与首页、文章、项目、笔记、归档、小记、关于和星球详情的代表页面。
- 实际操作：首页项目筛选；中文搜索、空结果、方向键选择、Esc 焦点归还、结果跳转；复制链接成功；手机目录跳转并收起；阅读进度、桌面目录与阅读模式开关；窄屏芥兰三维载入、搜索弹层打开关闭、回到图版移除 iframe。
- 修复检查中发现的窄屏关闭按钮换行、目录虚线样式冲突和文章标题的多余右侧留白。
- 只读独立代码复核未发现新的发布阻塞项；该复核不替代浏览器验证。

浏览器验证使用 Chromium 与模拟视口，未据此宣称真实手机、Safari 或微信完整兼容。五件模型及其几何未改动，本轮没有重做全部作品的美术验收或性能测试。
